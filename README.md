# Code Runner: Escape de los Bugs

Endless runner 2D arcade para el taller de egresados. Robot neón, bugs informáticos y récord local.

## Jugar

- Producción: https://juego-taller.codepulse.cl
- Controles: `ESPACIO`, flecha arriba o toque/clic para saltar

## Desarrollo

```bash
npm install
npm run dev
npm test
npm run build
```

Stack: Vite + TypeScript + Canvas 2D. Despliegue con nginx sirviendo `dist/` versionado.
